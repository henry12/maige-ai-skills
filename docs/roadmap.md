# 路线图

路线图表示方向，不承诺发布日期或尚未实现的能力。

| 阶段 | 范围 | 完成条件 |
| --- | --- | --- |
| 0：公开筹备 | 仓库结构、文档、贡献和反馈入口 | 能清楚区分规划与可用能力 |
| 1：动画独立包 | 从实际制作项目提取一个可独立运行的 Skill | 不依赖作者本机路径；样例可预览、修改并导出 |
| 2：小范围使用验证 | 使用自己的材料，并完成一次修改 | 有外部尝试记录，主要卡点和人工介入有据可查 |
| 3：首个可运行版本 | 发布包、完整案例、单一主环境支持 | 通过发布检查，说明依赖、成本和限制 |
| 4：按证据扩展 | PPT、去 AI 味或其他能力 | 有具体用户任务和维护资源，再决定优先级 |

## 已知与假设

- 发起者反馈既有 Skill 内容有收藏，但当前未收集到实际使用反馈。
- 收藏不能证明用户成功安装、完成任务、再次使用或愿意付费。
- 动画首发来自真实创作投入和兴趣；外部用户的需求与使用门槛仍待验证。
- PPT 成品生成和可编辑性、去 AI 味的额外文种、不同 Agent 产品兼容性都需要分别验证。

## 优先观察

记录尝试人数、成功完成样例人数、成功替换材料人数、完成修改人数、人工协助次数以及后续真实任务复用。数字需有明确分母和记录来源，不设未经验证的市场或转化率目标。

简历、公文、控制台／看板暂不建立空目录；先明确任务、输入输出、维护者和可复现样例。
