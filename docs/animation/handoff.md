# 动画能力接入清单

本文件供正在优化动画组件的实现会话使用，不要求改动原项目的规则或目录。

## 接入目标

在本仓库新增 `skills/maige-animation/`，以当前 direct Remotion 路线为起点，交付一个独立可运行的公开 Skill。组件数量按实测结果确定，不为凑数量迁移未稳定组件。

## 迁移范围

1. 选择已经实际使用、能说明价值的组件或场景。
2. 提取最低必要的指导、脚本、工程与样例；不复制整个内部视频生产流程。
3. 移除作者本机绝对路径、私有依赖、账号资料、未授权素材、内部审核状态和历史缓存。
4. 将需要的内容、颜色、尺寸或时长参数变成清楚的修改入口，说明哪些仍需要改代码。
5. 为外部依赖锁定版本，提供实际有效的预览与导出方法。
6. 记录源文件来源、改动与许可；有疑问的材料先不并入。

## 必须提交的成果

- 一个边界清晰的 `SKILL.md`，以及人类可读的 `README.md`。
- 自包含工程与最小样例。复制单个 Skill 目录到另一位置后仍能按说明执行。
- 至少一个完整公开案例：输入、预览、成品获取方式、源码位置、版本和验证记录。
- 至少一次修改后重新生成的证据，以及与原样例不同的内容适配记录。
- 更新兼容性表、Skill 目录和变更记录；通过检查后再将“筹备”改成实际状态。

## 不随迁移承诺的内容

不默认承诺任意动画、跨平台兼容、无模型费用、无人干预、特定耗时或效果提升比例。逐项按真实运行证据描述。

正式发布前按照 [发布检查表](../release-checklist.md) 核对。迁移工作宜在分支和 PR 中完成，便于审查公开文件范围。
