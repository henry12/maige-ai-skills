# 使用说明

## 当前状态

本仓库处于筹备阶段，尚无可安装 Skill。下载或克隆仓库只能获得规划和接入文档，不能生成动画、PPT 或其他成果。

请通过 [README](../README.md) 和 [路线图](roadmap.md) 查看进展。当前不提供未实测的安装命令。

## 首个 Skill 发布后的目标体验

1. 在支持列表中选择已经实测的 Agent 产品与环境。
2. 只安装所需 Skill，检查依赖、执行权限和费用来源。
3. 运行随包最小样例，打开成果预览。
4. 替换一段文字或一个参数，重新生成。
5. 再使用自己的材料，明确其中哪些内容可以被模型或外部服务处理。
6. 保留源文件；根据需要导出视频或其他成品。

首次成功的标准是“打开成果并完成一次修改”，不是仅看到执行成功提示。

## 材料与隐私

不需要把公司资料提交到 GitHub。反馈时使用脱敏内容或随包样例。Agent 在本地读取文件不代表内容一定不会传给模型服务；实际数据流取决于使用的产品、模型和配置，后续各 Skill 应明确说明外部调用。

用户未授权公开的文字、截图、声音和文件，不得进入案例或 Issue。仓库不默认加入遥测或上传机制。
