# Skill 发布检查表

此表用于未来可运行 Skill 发布；当前仅公开骨架，不表示这些项目已通过。

- [ ] 输入、输出、触发条件、不适用范围明确。
- [ ] 独立复制 Skill 目录后仍可运行，没有隐式仓库根目录或本机路径依赖。
- [ ] 依赖及锁文件齐全，实际安装、预览和导出命令已经验证。
- [ ] 最小样例能生成成品，替换材料和一次修改后重生成均已验证。
- [ ] 视觉检查覆盖文字溢出、布局、信息层级、节奏和实际输出尺寸。
- [ ] 明确源文件格式、可编辑范围及修改入口。
- [ ] 兼容性记录包含版本、环境和实际证据，未测项未写成支持。
- [ ] 公开案例的输入、成品、源文件、版本与人工处理说明一致。
- [ ] 密钥、个人数据、内部材料、日志和大体积缓存未进入提交或 Git 历史。
- [ ] 代码、字体、图片、音乐、模板及外部依赖的来源与许可已经记录。
- [ ] 外部服务、数据流、可能的费用和必要权限已说明。
- [ ] 分发包只包含运行所需文件；实际下载解压后复验，不只测试开发目录。
- [ ] README、目录、变更记录、发布说明和固定版本链接均已更新。
- [ ] 失败时给出明确原因和处理方式，不把部分输出标为完整成功。

无需为了一个文档调整重复执行完整渲染；运行检查应与实际变更和风险相匹配。
