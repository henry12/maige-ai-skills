# 麦哥的 AI 实战 Skills

把 AI 用进真实工作：从办公提效到业务落地，分享实用方法与实战复盘。

我们希望把实践中反复使用的方法，整理成能交付成果、能继续修改、能独立复现的 Agent Skills。优先做好视觉表达和实际使用体验。

> **当前状态：公开筹备中。** 本仓库目前只有项目骨架和接入规范，没有已发布、可安装的 Skill，没有安装命令，也没有已验证的产品兼容承诺。动画制作是首发方向，具体实现将在验证后接入。

## 我们如何判断一个 Skill 值得发布

- 用户提供自己的材料后，能拿到明确的成果，而不只是下一轮提示词。
- 有完整输入样例、输出预览、源文件和复现说明。
- 明确哪些内容可编辑，以及修改后怎样重新生成。
- 有真实运行环境、依赖、费用来源、已知限制和人工处理记录。
- 漂亮的展示效果与稳定复用分别验证，不用精修样片替代使用测试。

后续案例只展示已取得公开授权或明确标注的模拟材料。当前尚无公开案例，不使用未经验证的效果、市场或用户数据。
