# 案例

当前没有已发布案例。后续按 `examples/<能力>/<案例名>/` 组织。

每个案例应说明：

1. 要完成的实际任务，以及输入是公开、授权、脱敏还是模拟材料。
2. 输入文件和对应 Skill 的固定版本。
3. 实测环境、生成步骤、依赖和可获得的成本信息。
4. 完整成果预览、成品获取方式与可修改源文件位置。
5. 一次实际修改和重新生成的步骤。
6. 人工干预、限制与失败情况。

小型预览可进入仓库；大视频、渲染文件和发布压缩包优先放入对应版本的 Release。不要用不存在的下载链接或演示图片替代真实成果。不要在案例复制一套容易与 Skill 漂移的运行工程，优先引用固定版本的源文件。
